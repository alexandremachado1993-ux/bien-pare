# Plan du projet

**Objectif au 1er novembre 2026 :** présence publique professionnelle pour les deux univers, comparaison documentée des opportunités, un produit numérique prêt à vendre **si** les démarches personnelles sont faites. Aucun revenu n'est garanti.

## État au 26/10/2026
| Livrable | État |
|---|---|
| Recherche marché, fournisseurs, canaux, conformité (`research/`) | Fait (données de seconde main, confiance indiquée) |
| Classement et choix des produits | Fait |
| Site prototype (10 pages, 2 univers, 4 produits, sélection simulée, formulaire, tableau de bord) | Fait et testé localement |
| Pack Concours Serein (PDF 10 pages + aperçu gratuit 2 pages) | Fait (à relire par vous) |
| Sauvegarde GitHub | **Bloquée** : dépôt à créer par vous |
| Stockage des avis et événements | **Bloqué** : accord Supabase requis |
| Mise en ligne | Après GitHub, mentions légales et stockage |
| Vente du pack | Après SIRET, compte Payhip, CGV et médiateur |
| Vente physique | **Pas avant validation** (SIRET, REP, fournisseur, échantillon) |

## Calendrier jusqu'au 1er novembre
- **26-27/10** : recherche ✔, choix ✔, site ✔, pack ✔ · *Vous :* créer les dépôts GitHub, donner l'accord Supabase, lancer la demande de SIRET si vous voulez vendre.
- **28-29/10** : brancher Supabase, publier sur GitHub Pages, tester en conditions réelles · *Vous :* relire le pack, compléter les mentions légales.
- **30-31/10** : tests sur téléphone, corrections ; si SIRET obtenu : page Payhip, CGV, case de renonciation à la rétractation, puis activer `digitalCheckoutUrl`.
- **01/11** : mise en ligne du test d'intérêt ; diffusion gratuite avec liens `utm_source`.

## Rythme ensuite (4 à 6 h / semaine)
45 min diffusion et recherche · 2 h une amélioration · 1 h tests · 1 h analyse des avis et du tableau de bord. Une seule modification d'offre par période.
